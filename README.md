# 面试点评器（InterviewLiveNote）

[![License](https://img.shields.io/badge/License-MIT-green.svg)](#许可证与第三方组件)
[![Release](https://img.shields.io/github/v/release/lyckeven/InterviewLiveNote)](https://github.com/lyckeven/InterviewLiveNote/releases)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%2F%2011-0078d4)](#下载安装)

给别人答题时**实时听记 + 实时标记 + AI 点评**的 Windows 本地工具。默认声音来源是**电脑系统内录**（WASAPI Loopback），不需要麦克风、不需要虚拟声卡，也不依赖外部服务；转写在本地离线完成，音频不出本机。

## 功能特性

- **系统内录转写**：直接抓电脑正在播放的声音（也可切换为麦克风抓现场），VAD 最小静音判定 0.32 秒，说完一句约 0.3 秒定稿上屏，语音中途还有 0.3 秒一次的中间结果。
- **段落级计时**：按停顿、篇幅与话题词自动切段，每段记录起止时间、用时、字数、语速；段落头按钮有「亮点 / 硬伤 / 追问 / 口头禅 / ＋问题 / 备注 / AI速评 / 结构/点评 / 删除」，单段 AI 点评在「结构/点评」菜单里（需已配置 API Key），在段落上点右键也能直接打开同一菜单。
- **实时标记**：段落维度四类标记「亮点 / 硬伤 / 追问 / 口头禅」，键盘 `1`–`4` 打在选中的段落上（再按一次取消），另有「备注」与自定义问题标（四类之外的问题自己填，多条用分号分隔）；右侧汇总可点回原段落。
- **两档点评**：配置 API Key 走 AI 点评（对照参考要点与该题型的答题环节，题型未配置时按通用五环节：审题 / 提观点 / 重分析 / 抓落实 / 结尾）；不配 Key 走本地量化诊断（语速、口头禅、结构信号词、停顿、关键词覆盖）。
- **精简稿与要点**：去语气词、口头禅后的精简逐字稿（可「按结构看」，按答题环节分组），并可一键提取学生答题要点。
- **题库外部导入**：题库不随软件内置，需自行导入或新建，首次启动题库为空；支持纯文本、`.docx` / `.pdf` / `.txt` / `.md` / `.csv` / `.json` 文件与模板 JSON，自动切题并识别题型与答题结构，入库前可逐题核对修改。
- **多学生与历史**：一场之内可加多位学生分别作答；历史可按题型 / 学生 / 日期区间 / 关键词（题干或逐字稿）检索，可导出 Word 复盘稿。
- **手机接入**：局域网扫码用手机看逐字稿与标记，手机端可开麦把声音传回电脑（走 HTTPS 自签证书，满足浏览器要求的安全上下文）。

## 界面

主界面三栏：左侧「本题信息 + 题库」，中间「逐字稿 / 精简版」，右侧「标记汇总 + 点评」；顶栏放声音来源（「系统内录 / 麦克风」切换 + 设备下拉 + 电平条）、「开始听记 / 停止」与计时、搜题库输入框、「手机扫码」、「快速记录」、「精简要点」、「新建一场」、「历史记录」、「设置」。栏间分隔条可拖动调整宽高，双击复位；窗口是无边框桌面窗口，右上角自带最小化 / 最大化 / 关闭。

## 下载安装

安装包发布在 [Releases](https://github.com/lyckeven/InterviewLiveNote/releases) 页面，另有源码方式运行：

| 方式 | 适合 | 特点 |
| --- | --- | --- |
| 安装包（`面试点评器_安装程序_<版本>.exe`） | 长期在固定电脑上使用 | 有安装向导，自动建桌面快捷方式与开始菜单，装到当前用户目录，不需要管理员权限 |
| 源码运行 | 想改代码 / 自己打包 | 需自行安装 Python 依赖，见下 |

> 官方 Releases **只提供安装程序 exe**，没有单独发布绿色版 zip。项目打包产物本身是 onedir 目录（`dist\面试点评器\`），如需便携版可自行压缩该目录后拷走，解压即用、不写注册表，删掉文件夹即等于卸载。

- **运行环境**：Windows 10 / 11（x64），需系统自带 WebView2 运行时（Win11 与已更新的 Win10 默认具备）。
- **数据目录**：安装版与自行压缩的便携版共用 `%LOCALAPPDATA%\InterviewReviewer\data`（题库、存档、设置都在这里，卸载前请自行备份），日志在 `%LOCALAPPDATA%\InterviewReviewer\logs`。
- **首次启动**：双击图标后弹出程序自己的桌面窗口（内嵌 WebView2，不是外部浏览器），默认加载 `http://127.0.0.1:7788`；该端口被占用时会自动顺延到下一个空闲端口，无需手动改配置。此时题库为空，需要自己导入或新建题目。
- **单实例**：再次双击图标不会起第二个服务，会尝试把已运行的窗口调到前台（置前失败时退回用默认浏览器打开该端口地址）。
- **调试用浏览器模式**：命令行执行 `launcher.py --browser`（或 `python server.py` 后手动访问日志里打印的地址）才会用系统浏览器打开界面。

源码方式启动：

```
python -m pip install -r requirements.txt
python launcher.py
```

（`python server.py` 只起 Flask 服务、不开桌面窗口，适合调试后端接口。）

## 快速开始

1. **填题目**：左栏「本题信息」里填考生、题干、题型（下拉选，或点「＋新建」现场建题型）、参考要点；也可点「粘贴分析」让程序自动识别题型与答题结构，或点「从题库选」直接载入已存的题。
2. **选声音来源**：顶栏默认「系统内录」、设备为「系统默认输出（自动）」，即抓电脑正在播放的声音；插了耳机也会跟随默认输出设备的 Loopback；要抓现场说话就切到「麦克风」。
3. **点「开始听记」**：逐字稿按段落实时滚出，每段显示段号、段落标签、起止时间、用时、字数、语速。
4. **边听边标记**：点段落头的标记按钮，或选中段落后按 `1`–`4` 快捷键打「亮点 / 硬伤 / 追问 / 口头禅」（再按一次取消）；点「备注」给这一段写文字说明。句子级的修改在中间「精简版」里做：单击 / 拖选 / `Shift` 连选句子后，用上方工具条「改归属结构 / 拆句 / 合并 / 删除」，双击句子可直接改字。
5. **点评与存档**：点「重新点评」得到三段式点评（时间 → 优点 → 问题，问题带段号与秒级位置）；点「停止」会自动存档到数据目录的 `records\`（停止提示里会写「已自动存档」），生成 `<场次id>.md`（可直接给学生）与 `<场次id>.json`（可回看）；也可随时点「存档」，或点「导出复盘稿」把整场复盘（基本信息 / 时间分配 / 三段式点评 / 精简要点 / 精简逐字稿）导出为 Word，文件落在数据目录的 `exports\`。

## 题库导入

题库不随软件内置，需自行导入或新建，首次启动题库为空。题库面板有两个入口：「导入文本」（弹层标题「导入题库（文本 / JSON）」）与「导入 Word/PDF」（选文件）。导入弹层支持三种写法，最省事的是用模板：

**① 模板文件（推荐）**

仓库 `templates\题库模板.json` 就是标准题库格式，可直接用文本编辑器改内容；软件内「导入文本」弹层左下角有「下载模板」按钮，下载的就是这份模板（两题示例 + 八个字段的填写说明）。顶层结构：

```json
{
  "name": "题库名称",
  "items": [
    { "question": "题干原文", "qtype": "社会现象", "qtype_reason": "", "exam": [], "structure": [], "keys": [], "ref": "", "source": "import:template" }
  ]
}
```

每个字段的含义：`question` 题干（必填，唯一必需项）；`qtype` 题型名（与软件内置题型同名才会套用该题型的答题环节与点评要素）；`qtype_reason` 题型判定依据（考点 / 设问类型 / 难度之类的说明文字）；`exam` 审题分析，字符串数组，一段一条（「本题属于…」「审题点1：…」）；`structure` 答题结构，对象数组，每项形如 `{"stage":"提观点","label":"","points":["要点1","要点2"]}`；`keys` 精简答题要点，字符串数组；`ref` 参考要点全文（单个字符串，可换行）；`source` 来源标记（如 `import:fenbi`、`import:template`，仅作标识）。除 `question` 外都可以留空。

**② JSON 直接粘贴**

按上面同样的字段写数组即可；数组形式没有题库名，导入后存为「未命名题库」并保存为 `bank\未命名题库.json`，想自定义库名就在导入弹层里填题库名，或用对象形式 `{"name":"题库名","items":[...]}`（`items` 也可写成 `questions` / `list`）。JSON 必须以 `[` 或 `{` 开头才会走 JSON 解析，否则按纯文本解析；整体格式错误或缺 `question` 会提示原因而不入库。

**③ 纯文本粘贴**

按下面的格式（多题用 `===` 单独一行分隔，或直接以 `1. ` 之类的编号另起一行）：

```
1. 你单位要组织一次基层调研，领导让你负责，你怎么开展？
类型：组织管理
参考要点：明确调研目的与对象；科学设计问卷与提纲；组建队伍分工；深入一线访谈；形成报告并提出对策

1. 有人说基层干部要"能干"，有人说要"能说"，你怎么看？
类型：综合分析
参考要点：辩证统一；能干是根本；能说是沟通能力；两者结合；结合岗位谈落实
```

识别的键名比较宽松：题目行认 `1.` / `1、` / `（1）` / `第1题` 等编号开头；题型行认「类型：」或「题型：」（也认 `【类型】` / `【题型】`）；参考要点行认「参考要点：」「参考答案：」「答题思路：」「要点：」「答案：」「解析：」（也认带 `【】` 的写法）。粉笔风格的 `【考点】`「【粉笔审题】」「【解析示例】」「【备课要点】」等分段也能识别。

- **导入 Word / PDF**：点「导入 Word/PDF」先选解析方式（「AI 解析」补题型、答题环节与要点，会产生接口费用，未配 Key 自动回退「仅本地解析」），再选文件，可一次选多个 `.docx` / `.pdf` / `.txt` / `.md` / `.csv` / `.json`；系统自动识别「题目正文 / 类型：xxx / 参考要点：xxx」结构并批量切题，然后在「导入预览」里勾选、改题型与题干、补齐缺失项，再点确认入库；`.doc` 老格式不支持，请先另存为 `.docx`。
- **单题新增**：题库为空时点「＋ 新建题目」；已有题库时在左栏「本题信息」粘贴题干，点「粘贴分析」自动识别题型与答题结构，再点「一键入库」，入库弹层里可选已有题库或「＋ 新建题库…」。
- **删除**：题目列表里单题「×」只删这一题（二次确认）；题库名右侧「×」删除整个题库文件（二次确认，不可恢复）。
- **存放位置**：导入后存为数据目录下 `bank\题库名.json`（格式即模板格式），可长期复用；同名题库再导入时按题干去重合并。
- **AI 优化**：题库面板还有「AI 优化所选」「优化全库」与「一键撤销」，需在「设置」里配好 API Key 才会生效。

## 接入 AI

顶栏「设置」打开弹层，含「基础设置」与「题型结构管理」两个页签，「基础设置」里的相关项：

| 字段 | 说明 |
| --- | --- |
| 接口地址 base_url | OpenAI 兼容地址，默认 `https://api.deepseek.com` |
| 模型名 | 默认 `deepseek-flash`；也可填 `deepseek-chat`、`qwen-plus`、`deepseek-reasoner` 等 |
| API Key | 填自己的 Key，保存后不回显明文（输入框留空表示不修改已保存的 Key） |
| 界面风格 | 跟随系统 / 浅色 / 深色，切换立即生效 |
| 默认输入源 / 默认设备 | 系统内录或麦克风 + 具体设备，开始听记时按此自动选中 |
| 开启智能纠错 | 每段收段后调用 API 按上下文还原同音字 / 错别字 / 口误（需已配 Key，默认开启） |
| 停顿切段阈值 / 单段最长（秒）/ 单段最多字数 | 默认 1.5 秒 / 55 秒 / 240 字 |
| 开启段落即时点评 | 每段答完调用一次 API 评本段，费 token，**默认开启**（想省费用可手动关掉） |

点「测试连通」可先验证 Key 与地址，通过后即可生成 AI 点评。同一弹层里还有「手机接入 · 防火墙放行」（「一键放行」/「撤销放行」，电脑拦了入站连接导致扫码打不开时用）与「打开日志目录」。

不配 Key 时录音、转写、段落切分、标记、本地量化点评、题库本地解析与导入都正常可用；仅 AI 点评、AI 逐题优化、导入时的「AI 解析」这类需要模型的环节不可用（导入会回退到本地解析）。

## 快捷键

除特别说明外，快捷键都要求**焦点不在输入框 / 文本域 / 下拉框**内，且逐字稿里已有段落：

| 按键 | 作用 |
| --- | --- |
| 空格 | 开始 / 停止听记 |
| 1 / 2 / 3 / 4 | 给当前选中的段落（未选中则最后一段）打 亮点 / 硬伤 / 追问 / 口头禅，再按一次取消 |
| Enter | 打开选中段落的「备注」输入框（备注框内 Enter 保存、Shift+Enter 换行、Esc 取消） |
| Esc | 关闭最上层弹层 / 退出点评全屏 / 收起快速记录 / 取消句子改字或备注输入 |
| Delete | 删除精简版里选中的句子（同段至少保留一句） |
| Ctrl + Enter | 句子改字状态下，从光标处把这一句拆成两句 |
| ↑ / ↓ / Enter | 顶栏题库搜索框内选择候选题并载入 |

句子级操作（都在中间「精简版」里）：单击选中、拖选或 `Shift` 点两句连选，工具条有「改归属结构 / 拆句 / 合并 / 删除 / 取消手动归属 / 清空选择」；双击句子进入改字，`Enter` 保存、`Esc` 取消、`Ctrl+Enter` 在光标处拆句。

```
InterviewLiveNote\
├─ server.py              Flask 服务（默认端口 7788，被占用自动顺延；仅本机与局域网）
├─ launcher.py            桌面启动壳（pywebview 无边框窗口 + 端口探测 + 单实例）
├─ asr_engine.py          系统内录采集 + VAD 断句 + SenseVoice 识别 + 标点恢复
├─ ai_client.py           OpenAI 兼容客户端（点评 / 逐句速评）
├─ local_analyzer.py      本地量化诊断（不依赖 AI）
├─ paragraphizer.py       按段落切分与计时（停顿 / 篇幅 / 话题词三重规则）
├─ simplifier.py          精简稿（去语气词与口头禅）
├─ points_extract.py      精简要点提取
├─ question_analyzer.py   题干解析与题型判定
├─ corrector.py           识别结果纠错
├─ cert_util.py / firewall_util.py / log_util.py   手机接入证书、防火墙、日志
├─ static\                前端（index.html / style.css / app.js / mobile.*）
├─ templates\             题库导入模板（题库模板.json，接口 /api/bank/template 提供下载）
├─ default_data\          随包默认数据：question_types.json（题型结构）、config.json（默认配置）
├─ LICENSES\              第三方许可证全文
├─ THIRD_PARTY_NOTICES.md 第三方开源组件声明
└─ _packaging\            打包脚本（PyInstaller spec / Inno Setup iss / 版本信息 / 图标）
```

运行期数据（不在仓库内）：`%LOCALAPPDATA%\InterviewReviewer\data\`（`config.json` 设置、`bank\` 题库、`records\` 存档、`exports\` 导出的复盘稿），日志在 `%LOCALAPPDATA%\InterviewReviewer\logs\`。

技术栈：Python 3.13（便携版）+ pyaudiowpatch（WASAPI Loopback）+ sherpa-onnx（SenseVoice int8 离线中文识别 + Silero VAD + CT-Transformer 标点）+ Flask + 原生前端。

## 常见问题

**1. 逐字稿为空 / 不识别**
确认电脑确实在播放声音（系统音量不静音）；顶栏换一个 Loopback 设备试；查看 `logs\` 下当天日志有无报错。

**2. 识别串进无关声音**
内录抓的是整个系统输出，录制时不要同时播放音乐、视频或语音提示。

**3. 个别字识别错（同音字）**
当前用 int8 量化模型，取舍在速度；需要更高精度可换非量化 `model.onnx`（约 900MB）替换模型目录 `models\sense-voice\` 下的同名文件（也可用环境变量 `IR_MODEL_DIR` 指向别的模型目录）；配好 API Key 后，每段收段时还会自动做一次 AI 智能纠错，把同音字 / 错别字 / 口误按上下文还原（设置里关掉「开启智能纠错」即停用，需要单段重跑可在段落里手动触发）。

**4. 题库是空的 / 找不到题目**
题库不随软件内置，需自行导入或新建，首次启动题库为空；入口是题库面板的「导入文本」「导入 Word/PDF」与「＋ 新建题目」，字段写法见上文「题库导入」和 `templates\题库模板.json`。

**5. 端口被占用**
不用改代码：双击图标由桌面壳启动时，会从 7788 起自动向后找空闲端口（最多试 40 个），日志里会打印实际地址；想固定端口可设环境变量 `IR_PORT`，手机接入的 HTTPS 端口优先取该端口 +1（被占用时再顺延）。直接用 `python server.py` 起服务时不做端口顺延，只认 `IR_PORT`（默认 7788），占用即报错。

**6. 想让点评更贴教学口径**
改 `ai_client.py` 里的 `SYSTEM_PROMPT` / `CHECK_LIST` / `REVIEW_TEMPLATE`，把评分维度（审题、结构、内容、语言、岗位匹配）写进去即可；按题型细分的答题环节与点评要素则在软件「设置 → 题型结构管理」里改，不用动代码。

## 自行构建打包

```
python -m pip install -r requirements.txt
python -m pip install pyinstaller

:: 1) 生成 onedir 目录（产物：dist\面试点评器）
pyinstaller _packaging\interview_reviewer.spec

:: 2) 用 Inno Setup 编译 _packaging\setup.iss，生成安装包
::    产物名由 OutputBaseFilename 决定，当前版本为 面试点评器_安装程序_v2.7.0.exe
```

- 打进包里的除代码外还有 `static\`、`templates\`（题库模板，保证「下载模板」可用）、`_packaging\default_data\`、`models\`、`LICENSES\` 与 `THIRD_PARTY_NOTICES.md`，这些都在 `interview_reviewer.spec` 的 `datas` 里配置。
- 识别模型（SenseVoice）、VAD 与标点模型不打入仓库，需按 `interview_reviewer.spec` 中的路径放置后打包。
- 打包前确认 `_packaging\default_data\` 只含 `question_types.json` 与 `config.json`，不得放题目数据。
- 编译 iss 前把 `SrcDir` 指向 `dist\面试点评器`、`OutputDir` 指向自己的输出目录；升级发版时版本号需同步五处：`server.py` 与 `launcher.py` 的 `APP_VERSION`、`static\index.html`（含 `static\mobile.html`）的版本标识、`_packaging\version_info.txt`、`_packaging\setup.iss` 的 `MyAppVersion` 与 `OutputBaseFilename`。
- 需要便携版就自行压缩 `dist\面试点评器\` 目录（官方 Releases 不单独发布 zip）。
